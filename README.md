# 天气预报

卫星云图、台风路径和城市天气的静态网页应用。用浏览器直接打开即可；也可以加到主屏幕，像小程序一样全屏使用。不需要账号，也不需要 API 密钥。

当前功能：全球城市搜索、当前位置天气、24 小时与 16 天预报、空气质量、生活指数、动态穿衣指南、未来 2 小时风险卡片、过去 7 天与未来 16 天趋势曲线、可选日期与时间段历史天气查询、每日/逐时曲线、可拖动时间游标、卫星云图、高清城市底图、高清模式真实色/红外叠加、二维/三维地图、晨昏线与昼夜阴影、关键道路与城镇名称、国道/省道/县道/乡道/村道开关、不同颜色行政边界、红绿灯点位、地图选点同步天气、雷达回放、温度/湿度/风/气压/降水图层、CMA 与 NHC 台风路径、台风风圈与预报锥、预警列表。地图默认定位所选城市，点击“定位并放大城市细节”即可切换高清城市影像并放大到 12 级左右，之后可继续放大至约 19 级；高清模式可叠加低透明度真实色或红外图层。“3D 城市”显示道路、城市/城镇名称、建筑立体效果和可用的地形起伏，缩小到约 2.5 级时切换为球体地球，点击地图任意位置会自动回到天气页读取该点天气。天气首页显示今日日出、日落和日照时长；未来 2 小时按 +10 / +15 / +30 / +60 / +90 / +120 分钟连续提示。路线面板支持起终点、出发时间、路线和沿途天气点突出显示。云图透明度、风场尺度与阵风提示会随交互变化，放大城市时天气网格自动加密。天气支持手动刷新并约每 15 分钟检查，台风约每 10 分钟检查，地图雷达约每 5 分钟检查。

线上地址：https://syandavid.github.io/weather-forecast/

## 本地预览

在仓库目录启动静态文件服务（端口 8080），再用浏览器打开本机该端口。不要用 file 协议打开，否则无法注册 Service Worker。

```bash
python -m http.server 8080
```

## 加到主屏幕

iPhone：用 Safari 打开（不要用微信内置浏览器），底部分享，选添加到主屏幕。从主屏幕点「天气预报」即全屏独立窗口。

Android：Chrome 打开后，菜单里选添加到主屏幕或安装应用。

电脑：Chrome 或 Edge 可安装为独立窗口。宽屏是侧栏加内容，卫星和台风页提供完整地图。

## GitHub Pages

按 `main` 分支根目录发布。仓库 Settings 的 Pages 中选择 Deploy from a branch，分支 `main`，目录为根目录。

## 数据来源（全部公开、无密钥）

- 天气与预报：Open-Meteo Forecast
- 历史天气：Open-Meteo Historical Weather（模型/再分析数据，不等同于气象站实测）
- 城市搜索：Open-Meteo Geocoding
- 空气质量：Open-Meteo Air Quality
- 真实色卫星：NASA GIBS（VIIRS / MODIS True Color）
- 东亚可见光与红外：NASA GIBS（Himawari AHI）
- 雷达：RainViewer
- 西北太平洋台风：中央气象台 CMA
- 大西洋与东北太平洋台风：美国飓风中心 NHC
- 台风页底图：Esri Canvas World Dark Gray（无密钥；若不可用则 OSM 加深）
- 城市高清影像：Esri World Imagery
- 道路与城镇名称：Esri World Transportation / World Boundaries and Places
- 三维城市底图：MapLibre GL JS + OpenFreeMap Liberty；地形：Mapterhorn 公共 DEM
- 红绿灯与细分道路/行政边界：OpenStreetMap Overpass 公共查询服务
- 路线：OSRM 公共路线服务；沿途天气：Open-Meteo Forecast

预警页优先列出在编台风，再根据未来 2 小时降雨、雷暴、阵风以及气温、降水、大风、低温、大雾阈值生成本地提示。没有生效项目时显示「目前没有生效预警」。本项目不替代官方紧急预警。

## 卫星图像能力边界

当前真实色图层是 NASA GIBS 的 VIIRS/MODIS 产品，云图透明度可以降低整张卫星影像的遮挡感，并通过城市标记保持所选城市清晰置顶；“高清城市”切换到 Esri World Imagery，支持 10 级以上、最高约 19 级放大查看城市细节，但它是底图/影像，不是实时云图。VIIRS 适合区域级观测，不是米级实时城市底图；Himawari 红外更新更频繁但空间分辨率更低。页面当前使用 Open-Meteo 的 15 分钟预报字段，数据源未提供时会对小时数据做插值，并在界面注明来源。下一阶段若接入后端，可用 Sentinel-2 10 米多光谱 + 云概率做多时相无云合成，阴雨时再叠加 Sentinel-1 SAR（全天候、雷达质感），但这需要合适的数据服务、配额和缓存策略。

晨昏线采用太阳位置近似计算，二维地图显示夜侧阴影和黄色分界线，三维地图也同步显示；三维球体、道路、城镇、建筑和地形效果依赖浏览器 WebGL 以及公开地图/DEM 数据覆盖，不能保证每个地区都有同等细节。高清模式是 Esri 城市影像底图叠加 NASA 卫星层，真实色/红外本身仍受原始产品的分辨率、云量和更新时间限制。

道路细分、彩色行政边界和红绿灯点位在城市级缩放时按当前地图范围查询 OSM；公共 Overpass 服务可能限流、超时或暂时不可用，此时 Esri/三维底图的道路与边界仍可用。红绿灯功能显示的是 OSM 中登记的信号灯点位，不代表当前信号灯相位。路线查询使用公共 OSRM，适合产品验证；它不提供实时拥堵速度，后续要做真实交通状况需要接入高德、百度、腾讯或商业交通服务，并申请密钥。

台风图上的“中心/风眼”是路径资料中心估计；只有带有足够空间分辨率的雷达或卫星原始产品才可以判断真实眼墙，当前版本不会把估计点伪装成真实风眼。

## 台风快照

浏览器先请求 CMA 与 NHC 实时数据；若被网络拦截，则回退到仓库内快照文件。定时工作流每半小时抓取一次并提交。也可在 GitHub Actions 页面手动运行该工作流。

## 文件

页面与逻辑都在 `index.html`，无需构建。另有 PWA 清单、Service Worker、图标、台风快照、抓取脚本和 GitHub Actions 工作流。

## 本地校验

提交前运行：

```bash
python scripts/validate_project.py
```

该检查不访问外部网络，只验证关键文件、PWA 清单、台风快照结构和抓取脚本语法。GitHub Actions 会在每次推送和 Pull Request 中自动运行同一检查。

## 维护约定

- `main` 始终保持可部署；新功能使用 `feat/` 分支，修复使用 `fix/` 分支。
- 有用户可见变化时更新 `CHANGELOG.md`，稳定节点使用 `v0.x.y` 标签。
- 台风快照是降级数据，不是紧急预警；页面始终显示数据来源和更新时间。
- 外部地图、卫星和天气服务的使用条款、访问限制与归属信息需要持续复核。

更完整的发布、数据更新和故障排查说明见 [`docs/MAINTENANCE.md`](docs/MAINTENANCE.md)。
